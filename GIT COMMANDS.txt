GIT COMMANDS – FETCH & REBASE WORKFLOW

1. Check current branch
git branch

2. Switch to your working branch
git checkout feature-login

3. Fetch latest changes from remote
git fetch origin

4. Rebase your branch onto main
git rebase origin/main

5. If conflict occurs
git status
(fix conflicts manually)
git add <file-name>
git rebase --continue

6. Abort rebase if needed
git rebase --abort

7. Push rebased branch safely
git push origin feature-login --force-with-lease
